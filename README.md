# ResumeIQ – AI Resume Analyzer

AI-powered resume analyzer that scores resumes, extracts skills, matches them with job descriptions, checks ATS compatibility and recommends suitable roles — for any profession.

Built with Flask, spaCy, scikit-learn and Groq AI.
